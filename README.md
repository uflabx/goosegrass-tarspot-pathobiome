# Goosegrass Tar Spot Pathobiome

This repository contains R scripts and supporting data associated with the analysis of fungal communities and host-associated ascospore germination in corn (*Zea mays*) and goosegrass (*Eleusine indica*) affected by tar spot.

## Repository structure

### Microbiome analysis

`microbiome/script/TS-GS_Microbiome_Analysis-newPhyllachora.R`

R script used for the fungal community and metabarcoding analyses.

`microbiome/data/UNITE_19.02.2025_plus_new_Phyllachora.fasta`

Augmented UNITE ITS reference database used for taxonomic assignment. The UNITE 19.02.2025 database was supplemented with recently described *Phyllachora* reference sequences.

### Host preference analysis

`host_preference/script/host_preference.R`

R script used to analyze host-associated ascospore germination on corn and goosegrass leaf sheaths.

Supporting datasets:

- `host_preference/data/leaf_sheath_germination.csv`
- `host_preference/data/glass_germination.csv`

## Sequence data

Raw ITS metabarcoding sequence data are deposited in the NCBI Sequence Read Archive. Accession information is provided in the associated manuscript.

Sanger sequences used for taxonomic and phylogenetic analyses are deposited in GenBank, with accession numbers provided in the associated manuscript.
